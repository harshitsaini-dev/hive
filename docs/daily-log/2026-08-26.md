# 2026-08-26

## Choosing mailboxes, when there are forty of them

Every account control in the app was a single-choice dropdown — fine at three
mailboxes, useless at forty. The question people actually have is "these
five", and a blind scroll through forty rows could not ask it.

One `AccountPicker` now serves the mail filters, the analysis panel and the
rules wizard: a search over the address, checkboxes, and an "Add these N" that
takes everything the current search matches, so nine related mailboxes are one
click rather than nine. An empty selection means *all of them*, which is the
convention the rest of the app already used for an unset account filter and
keeps the common case a single glance.

Both the search endpoint and the analysis run now take a list of account ids
rather than one, so the scope is honest all the way down rather than being
faked by running the same request several times.

## Senders picked, not typed

A cleanup rule runs unattended against a query written weeks earlier. An
address typed from memory is how that query quietly matches nothing for ever,
and nothing in the app would ever say so — a rule that matches zero looks
exactly like a rule that has already done its job.

So the wizard asks for senders as a list to tick, sourced from the local index
with a count beside each. Cheap only because it is local: the same list from
Gmail is a metadata read per message. Several senders fold into one
`from:(a OR b)` clause, which is one query Gmail can answer and one number the
check step can show.

Several mailboxes save as several rules, one per mailbox, rather than one row
that quietly acts in several places — pausable and auditable apiece, and the
runner, the audit trail and the row shape are all untouched. The check step
sums the count across every chosen mailbox, because a figure from the first
account would understate what the rule clears without ever admitting it.

## The rules page, side by side

Stacked, whichever card went second was effectively hidden: the index draws a
row per connected mailbox and forty of those bury anything below them. Two
columns now, index left and rules right, collapsing back to one below 68rem —
and there, rules first, because on a phone the top of the page is the only
place anyone looks.

192 Playwright tests, green headed and headless. Three existing tests changed
rather than broke: they asserted the single-account dropdown and the stacked
layout, both of which were deliberately replaced.
