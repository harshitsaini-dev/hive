### Things that were nearly mistaken for bugs

- An audit row showed a mangled em dash. It turned out the corruption was in
  the curl command used to test it, not in the app — a Node-side request with
  the same subject stored perfectly. Worth the ten minutes it took to check
  rather than "fixing" working code.
- A 500 on every request after the TLS switch looked like a proxy config bug.
  The actual cause was a stale Vite process from before the switch still
  holding port 5173 and answering the health check with the old HTTP proxy
  target. start.bat now clears the ports, not just the PID files.

### A limit that was too tight

The first rate limit on /auth was 30/min, which the test suite tripped
immediately — a fair signal, since /auth/me runs on every page load. Raised to
200/min and documented that the real anti-brute-force control is the
database-backed OTP limit (5 codes per 15 minutes, 5 guesses per code), which
survives restarts and cannot be dodged by changing IP.
